# 🪟 Windowsmith

**Windowsmith** is a sleek, browser-based visual GUI designer for Python's popular **CustomTkinter** library. Build desktop application interfaces using an intuitive drag-and-drop workbench and instantly export clean, production-ready Python code!

![Status](https://img.shields.io/badge/Status-Active-success) ![Tech Stack](https://img.shields.io/badge/Tech-HTML5%20%2F%20JavaScript-blue) ![Library](https://img.shields.io/badge/CustomTkinter-Python-orange)

---

## ✨ Key Features

* **Visual Workbench & Drag-and-Drop:** Easily place and arrange widgets with snap-to-grid alignment.
* **Real-time Python Code Generation:** Instantly generates clean CustomTkinter code supporting both Class-based and Script-based layouts.
* **Comprehensive Widget Palette:** Includes buttons, labels, entries, textboxes, checkboxes, radio buttons, switches, sliders, progress bars, combo boxes, option menus, segmented buttons, and nested frames.
* **Detailed Inspector Panel:** Fine-tune properties, colors, fonts, and dimensions for every widget on the fly.
* **Built-in Templates:** Jumpstart your projects with pre-built layouts like Login forms and Preferences panels.
* **Dark/Light Preview:** Preview your desktop app layout in both dark and light themes dynamically.
* **Responsive Interface:** Designed to work smoothly across various screen sizes.

---

## 🚀 Quick Start

1. Open `windowsmith.html` directly in any modern web browser.
2. Drag widgets onto the window canvas or click them from the palette.
3. Customize your layout using the inspector panel.
4. Click **Copy Python** to copy the generated code to your clipboard.
